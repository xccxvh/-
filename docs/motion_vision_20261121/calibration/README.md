## 当前机位采样

实物纸尺 12 cm 为 O，朝纸尺数值增加方向为正。当前机位的正式输入为主机 `7/motion_20261121/runs` 内的独立摆放原片。每段取完整 150 帧。首段 `fit_m6` 没有读帧时钟，经现场确认只在静态回放中取帧号 / 30 秒；其余使用 `frames.csv` 的单调读帧时钟。

|用途|轨道位置 cm|对应纸尺 cm|现场动作|
|---|---|---|---|
|拟合|−6、0、+6|6、12、18|沿同一基准对准球心，每处静置拍一段|
|独立异位置检验|−5、+3、−3、+5|7、15、9、17|每次取走球，按实物刻线重新摆放，完整保留失败帧|
|零点复测|0|12|重新放置，单独检验零点偏差|
|复核原阶段双轮要求|−5、−3、+3、+5|7、9、15、17|第一轮完成后每处再独立摆一次，共四段|

固定相机、焦点、分辨率和杆姿态，记录真值、原片、帧时钟及当次摆放 ID。手和挡具退出球冠及尺块的视野后开录；用中帧和两端帧核对球位和遮挡。第二轮从头摆放，拆分同一段或换文件名都无法增加独立次数。换参考、算法、内参或 ROI 后，同一批真实原片可在新绑定下重新回放。

## 离板流程

逐帧用当前配置的三个尺块和上缘检测配准，再调用球检测和跟踪器。raw 使用原图参考坐标。points 以已校验内参矫正当帧的参考点和球点，重新估计变换。每种模式独立构建绑定，各自用三个拟合点的轴向像素中位数等权线性拟合。每点至少 20 个同帧有效采样，只映射拟合像素域内的值。既有模型、旧坐标 CSV 和用于限制搜索区的尺刻线锚点均未参与拟合。

逐次摆放以整段为分母，报告有效数、覆盖率、MAE、最大绝对误差及最长连续缺测。异位置验证不使用拟合刻度。零点重摆单列，避免掺入异位置指标。依第一阶段标准，每次独立摆放覆盖率至少 95%（150 帧至少 143 帧），最大绝对误差至多 0.3 cm，四个非零位置各有两次独立摆放。报告中的厘米比较均为静态精度。

从任意目录执行，输出指定为尚不存在的目录。以下示例运行当前机位两轮及错放记录。冻结后将 `MOTION_REPLAY_JETSON` 指向实际冻结的 Jetson 源码，`--config` 指向配套冻结配置和相对路径下的参考图。两种模式分别校验相机、焦点、参考及内参身份。

```bash
host=/home/user/桌面/jetson_nano/7
repo=/home/user/h_contest_vision_repository
cal="$repo/docs/motion_vision_20261121/calibration"
MOTION_REPLAY_JETSON="$repo/Jetson" OPENBLAS_NUM_THREADS=1 python3 -B "$cal/replay.py" \
  "$host/motion_calibration/field_recheck" --field \
  --config "$repo/Jetson/config_motion_topview_20261121.json" --export-model
```

可在 `--field` 后列出已到片的摆放名。现场首次 `verify_p3` 标称纸尺 15 cm，操作者复核首中末实见约 18 cm，原片及原标称保留；回放只记录像素证据，不赋实物真值。第二轮 `verify_p3_02` 同样标称纸尺 15 cm，但首中末均在 11 附近；原标签、哈希和原片保留，两段都不计样本或分母。正式 +3 cm 用 `verify_p3_retry` 和 `verify_p3_02_retry`。清单以外另有重摆轮次时使用 `--videos DIR --placements placements.csv --index capture_index.csv --motion`。两个 CSV 沿用第一阶段列名，清单每行指定唯一 run、role、cm，索引记录 run、file、sha256、frames、role、known_cm。零位复测 role 用 `repeat_zero`。回放逐个校验文件哈希及实际帧数，新目录中有逐帧 CSV、逐模式绑定、摆放汇总和评估 JSON。输出的临时绑定仅用于追溯样本。在最终冻结版本上可加 `--export-model`，拟合充分但双轮失败时只导出不可加载的系数审计；只有逐次双轮验收及本批 O 复测通过才导出正式模型。加载器自身按位置汇总，单轮通过和双轮通过分别记在 evaluation.json 的 measured_round_passed 和 passed。接入时该模式的 `rail_coordinates.calibration_file` 应指向匹配绑定的模型，并确认正常加载器返回 validated。
