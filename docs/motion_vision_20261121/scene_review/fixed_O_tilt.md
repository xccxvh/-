# 固定 O：有效输出与纸尺复核

原片 895 帧，旧版与新版均有完整逐帧行，现场处理了 725 帧。三个日志均已逐行按帧号与 frames.csv 的读帧时钟对齐。旧版有效 76 帧、新版 105 帧、现场 87 帧，三者并集 111 帧。逐格核对并集中所有有效标记，可见钢珠紧邻黑色工具右端，标记都在球身。原片首、中、末第 0、447、894 帧的球心横坐标目测约 625–627 px，尺面印字“12”对应的长刻线约在 642–643 px。球心沿图像竖直方向投影至纸尺，均比该长线偏左约 16–18 px，约为相邻长刻线间距的四分之一。图像横向投影包含视差；物理 O 点仍以现场放置定义为准。第 0、447 帧也可直接从原图看到球，两个离线版本在这两帧均报告参考匹配弱/歧义。
