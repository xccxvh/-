# 三场景原片独立复核

固定 O 的真球紧邻黑色工具右端。第 0、447、894 帧的球心均在纸尺“12”长刻线左侧约 16–18 px。三场景合计 676 个不同场景帧有有效输出（含 moving_free 的 digits 全帧回放），逐帧查看了这些输出的位置，未发现标记落在纸尺、工具或端挡上。多个无效帧中钢珠清楚可见。

* [固定 O 详情与尺面对照](fixed_O_tilt.md)。第 866–871 帧的真球在原处，旧版有效，新版先拒绝身份、后重新建立。
* [parked_free 详情与变化位置](parked_free.md)。新版新增的 101 个有效位置均落在球身。球曾滚过中部，后段在左端挡旁仍清楚可见，多处没有输出。
* [moving_free 详情与现场对照](moving_free.md)。第一套新配置的 13/895 与 Nano 之间含配置变更。与现场完全同配置的 digits 全帧回放有效 462/895；按 Nano 的 366 帧独立复跑，有效位逐帧对齐（159 帧有效），三路有效并集 464 帧均已核图，未见错误目标。

每组在完整帧号范围取含首末的 13 个等距网格点，三个场景均使用同一批帧号。另从新增、丢失、共同有效位置移动至少 1 px、现场处理后无效等类别中取样。无标记自由滚球网格另存了目测横坐标以便对照。三场景的变化类别均未出现共同有效且移动至少 1 px 的帧。每组另对全部有效输出做原片目视核对。现场跳过的帧以 skipped 标出，计数分母为各自处理的帧数。图像判据为有效坐标是否落在可见球身；无效帧仅作抽样，没有逐帧真值或厘米误差统计。[无标记网格目测记录](unmarked_grid_visual.csv) · [输入文件校验值](input_sha256.csv)
