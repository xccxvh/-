# parked_free 图像核对

原片 895 帧，现场处理 528 帧。先以原片做 13 点等距抽样，再对齐旧、新回放和现场日志。第 74、149、224、372、447 帧可见球在轨道内不同位置；第 0、298 帧及 522、596、670、745、820、894 帧，球贴近左侧绿色端挡。第 224 帧球在轨道中部，两个离线版本均无有效输出。第 649 帧端挡旁可见球，三份日志都没有候选。

旧版参考有效 110 帧、像素有效 0 帧；新版分别为 445、101 帧。现场像素有效 26 帧。全部 101 个新增有效位置已目视检查，均位于可见球身；现场有效坐标也在这些帧，取整到像素与新版相同。部分高速帧有横向拖影，核对判据为坐标是否落在可见球体，未测量精确球心误差。
