# 三数字框旋转跟踪的离板回归

**在 moving_free 实际处理的 366 个帧号上，桌面轨道阶段 P50 从 11.45 降到 5.60 ms（−51%），P95 从 15.23 降到 7.78 ms。** 286 次原重定位中有 221 次改用当前帧的导引复核。333 个参考有效帧、159 个像素有效帧的帧号及其三块匹配点、原点和钢球坐标全部一致。已有现场日志的原重定位 P50 为 77.66 ms，原直匹为 19.73 ms。候选耗时均为台式机实测，未对其板端延迟或实际采帧率作外推。

## 同一帧如何确认身份

- 独立副本只在 `adaptive_search=True` 且 `rotation_recheck=True` 时进入新分支。上一帧通过旋转复核且变换仍有效时，由该姿态算出本帧三个小窗中心。各窗半径 12 px，并与绝对搜索预算相交。
- 在三个小窗内读取本帧自己的原始峰。三个局部峰均须有原始竞争间隔，至少一块有强分数，原始三点的尺度、转角和残差须通过原门限。三块原始峰本身都强时优先走全窗直匹。需要旋转复核时，用本帧提议重新估计变换，在每一块的**全部可见 ±96 px 搜索域**做校正后的 NCC。全域胜者必须落回该块的历帧导引小窗才可作为 `rotation_track`。这样同一张响应图同时完成局部候选确认和远处竞争峰检查。
- 每个当前模板须达到 NCC ≥0.85、排除主峰邻域后的间隔 ≥0.05。保留原采样边界、三点残差 ≤2.5 px、尺度 0.9–1.1、图像转角 ±5° 以及下游上缘检查。最终变换取自本帧三处实测点。导引失败回到本帧全域重定位，整帧失败立即清空映射。全局直匹的三块也都在完整可见域比较，冻结实现直匹时仅第一块始终做全域竞争。
- 全域原始匹配和旋转提议共享本帧计算结果。三个重计算任务可在共享的有界工作池中并行，提交变换仍按帧串行。副本构造参数 `search_workers=1` 可单独运行算法；默认 3。两个值均不改变搜索域及阈值。该参数尚未接入配置 JSON。

## 五段完整回放

每段均有 895 个原始 JPEG。台式机 Intel Core Ultra 5 125H、OpenCV 4.8.1，OpenCV 内部单线程、OpenBLAS 单线程。每帧只解码一次，两套独立轨道、球检测与跟踪流水线交替先后执行，按原时间戳推进。墙钟只计 `RailDetector.detect(force=True)`（配准和上缘），不含解码、球检测和写盘。五段均使用同一个三数字框配置；旧录像两段也重新用此配置处理。

| 原片 | 原/新参考有效 | 原/新像素有效 | 轨道 P50 ms 原→新 | 轨道 P95 ms 原→新 | 原重定位→新重定位 |
|---|---:|---:|---:|---:|---:|
| moving_free | 824 / 824 | 462 / 462 | 11.66 → 5.96 | 14.94 → 8.41 | 688 → 147 |
| parked_free | 575 / 575 | 159 / 159 | 5.83 → 4.80 | 13.50 → 7.64 | 229 → 101 |

跨 4,475 帧的平均轨道耗时为 5.93 → 4.78 ms。冻结回放与归档三数字框日志的轨道原因一致；候选与冻结的参考有效、拒绝原因、像素有效、坐标状态也逐帧一致。**旧两段几乎全是直匹，三块做全域竞争使 P50 分别增加 0.58 和 0.72 ms。** fixed_O_tilt 的 P50 增加 0.79 ms，P95 降低 5.59 ms。

## 帧号子序列及线程消融

另建两套跟踪器，只喂入现场处理的 366 个帧号，避免用离线连续 895 帧的历史状态代替实机历史。以下同帧轨道耗时为桌面 P50。

| 候选路径 | 帧数 | 原 ms | 新 ms |
|---|---:|---:|---:|
| 导引旋转复核 | 221 | 11.62 | 5.65 |
| 全域重定位 | 65 | 11.61 | 6.95 |
| 直匹跟踪 | 47 | 2.97 | 3.84 |
| 仍拒绝 | 33 | 6.79 | 5.04 |

固定同一 366 帧独立重复两遍、轮换三种运行顺序。合并 732 次的 P50 墙钟 / 进程 CPU 时间分别为冻结 **11.43 / 11.46 ms**、单工作线程候选 **7.07 / 7.11 ms**、三工作线程候选 **6.02 / 10.00 ms**。单线程已获得主要加速，三线程再缩短墙钟但消耗更多 CPU 时间。板端与采集、解码共同运行时的资源竞争仍待实测。[逐帧线程消融](workers.csv)

## 误锁及遮挡

- 五段共 **4,071 个参考有效帧**。除 baseline 第 814 帧外，候选与冻结三处匹配点完全相同。该帧中块仍在同一对印刷数字之间，从 (691, 670.5) 到 (690, 670.5)，其余两块未动。原点差 0.331 px，沿轨坐标差 0.320 px，钢球图像 x 坐标相同。该帧四个不参与配准的数字窗均独立通过原分数和间隔，最大回投差 0.791 px。[第 814 帧放大图](compare_baseline_814.png)
- 每 45 帧抽样并加入上述变化帧，在 88 个参考有效帧上另行检查四个不重叠数字窗，共 317 个独立窗口通过门限。moving_free 合格独立峰的最大回投差 4.55 px；其三模板输出与冻结值逐点相同。数据支持“没有观察到新增误锁”，现场原片没有逐帧绝对位置真值。[独立核对明细](witnesses.csv)
- 已知真值的 160 帧仿射运动包含跳变、±3.8° 范围的旋转和尺度变化。两版均通过 160 帧，三块对已知位置的最大误差均为 1.305 px。另在冻结参考图和实拍旋转复核帧上分别遮挡单块、制造相距 86 px 的单块完整副本、单独移动一块 12 px，以及输入空白或模板出画。候选在 30 次负例中均拒绝（空白、出画输入重复）；冻结实现接受了 6 次单块重复挑战中的 2 次。另测格式变化、当前遮挡后 70 px 首帧重定位和无映射输出。[压力测试逐项结果](stress.csv)
- 四项独立单测加 47 项相关既有单测通过。对两套原始时间轴的回放，可从 [moving_free 全片](moving_free_all.csv) 和 [现场 366 帧子序列](moving_free_board366.csv) 下钻到具体帧。
