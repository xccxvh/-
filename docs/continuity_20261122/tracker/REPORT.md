## 启用受限运动补搜的联合复跑

以 `python3 -B docs/continuity_20261122/tracker/replay.py --guarded` 重跑 833 个现场处理帧，同时向补搜与跟踪器传入原始采集时间。第 147 帧是普通 Hough 确认。第 148、149 帧各自通过双模板复核与球缘拟合，检测器标记 motion_blur，实际置信度均为 0.825。此时球离边界仍远。跟踪器仅保留第 147 帧的强身份和原始时间戳；补搜每次清空穿界和回边计数，不能充当快速路径的任何一个实测样本。

联合回放从第 196 帧的界内普通圆开始，第 198 帧仍无候选，第 199 帧仍在获取。第 200 帧普通圆首次快速确认，中心 (315.37, 575.30) px。固定同一补搜检测器，原跟踪器有效 438 帧，修订后为 441 帧，新增 200、201、202，零个原有效帧变无效。目标空档为 149→200 的 1.705038 s。全段最大间隔仍为 246→301 的 1.846973 s。[启用补搜的逐帧数据](guarded_chronology.csv) · [同帧裁图](guarded_review.jpg)

只有当正常跟踪接受唯一且具有检测器补搜标记的当帧圆、补搜及旧锚点距边界均大于两倍直径、原锚点距当帧不超过 100 ms、相对边界稳定、运动同向且残差不超过原位置噪声容限、外观相容时，才保留旧锚点。任何一个条件未通过均清空边界证据。冷启动、无标记弱圆、歧义、参考跳变及过时输入的回归在独立跟踪测试中验证。

## 接口与有效条件

调用方式为 `tracker.update(candidates, ts, search_bounds=(left, right))`。无有效物理搜索区时传 None。冷启动仍需配置的正常获取帧数。快速路径需身份检查启用、唯一且通过普通关联的 topview_circle 候选，以及至少 0.85 的置信度。出向需在最近 0.45 s 内有相容的已确认身份，并观察同侧球缘从完整界内移至跨界。至少一个实测空帧之后，1.6 s 内在同侧半径范围内重新发现，此后须有三个实测圆，后两次连续；每次向内移动至少 3 px，同时通过普通位移门限、相对边界、直径、高光与高度检查。首次回边后可容许一次短暂空帧；任意两次用于确认的实测之间最多 0.13 s。输出传递当帧圆心。正常路径原有的无效预测状态继续由其有效位区分。时间倒退、参考缺失、过大移位、竞争候选及外观冲突均清除快速证据。

本机使用 `python3 -B docs/continuity_20261122/tracker/replay.py` 复跑。脚本读取原始 MJPEG 和现场处理帧号，另外固定 1e30933 的检测与跟踪源码作为对照。外观判断仅在实际有候选的当帧计算。参考测试夹具修正后，联合版本离线全集 271 项全部通过。跟踪专项 16 项通过，包含左右对称返回、冷启动、超时、重置、时间反转、参考移动、弱候选、歧义与反向运动。[回放脚本](replay.py) · [联合版本离线全集日志](tests.log)
