# 运动模糊圆心补搜离线验收

在 1e30933 检出上保留显式开关 `ball.motion_blur_recovery: true`。缺省关闭。调用方必须把与跟踪器相同的采集或录像时钟传给 `BallDetector.detect(..., timestamp=ts)`。缺失时钟、无效参考、普通 Hough 多解、运动停止或反向均不能授权连续补搜。圆心沿用 `topview-circle-v1`，沿用原有标定绑定和输出门控。开关属于绑定的 ball 配置，修改后的代码哈希也参与绑定。

## 重点空档

147 和 203 是原现场有效端点。148、149、151、152、198 的球附近普通 Hough 提案被轨沿高度过滤，其中 151 在现场跳过。150、154、155 有提案通过高度门后因圆周支持不足被拒；153 两类拒绝都有。原始两轮搜索在若干帧根本没有提出靠近钢珠的第一轮圆。156–158 已有候选但现场在重获。159–194 的目视球心在左界外。195 贴界，196 有候选，197 跳过，198 又回到无候选。199–202 继续重获，203 输出。逐帧表中的 Hough 拒绝原因取自原验证器的实际执行分支，球附近指横向与人工估读位置相差不超过 40 px。[57 帧阶段表](gap_stages.csv) · [每个提案及首次拒绝原因](gap_proposals.csv)

阶段表的 `paired_near`、`new_x` 和示例图绿色圆来自已否决的宽松实验。紫色圆来自独立的左界外 24 px 离线控制。离线控制在 159、160、161、195 帧测得距左界 −1.45、−14.42、−16.86、−1.92 px。158、196 的普通圆在左界内 +10.64、+16.12 px。运行时始终要求初值及拟合中心在原 ROI 内。[阶段代表图](gap_examples.jpg)

## 保留的运动条件

连续三次唯一普通 Hough 给出相对 ROI 左界的两段同向速度，各在 150–1200 px/s 内，速度比 0.45–2.2。在普通测量消失时，以最近两次实际球心的 49×49 灰度窗分别匹配当前 69×73 窄窗。两个峰均须在内部，相关系数分别至少 0.78 和 0.88，两峰相距至多 7 px。窄窗内必须只有一对合格横高光。以这对高光提议半径 24、27 px，用原始圆周、拟合、轨沿、ROI 和球内高光检查取实测圆心。圆心须在两个模板峰 7 px 内，沿轨位移与普通测量速度的比值在 0.5–1.8 内。

第一张补搜距末次普通圆最多 75 ms。仅当第一张也通过圆心实测时，才可对第二张执行同样的当帧验证，且两张补搜间的实际速度也须与末次普通速度一致。总时限 100 ms，一次拒绝即清空，第二张之后重新积累三次普通测量。普通圆竞争按原始候选数判断。所有输出均由当前帧像素拟合。第 198 帧之前越界后只有第 196 帧一个正常圆，无法授权补搜。

## 否决的变化与负例

宽松的双高光提议可补到 148–150、152–155、198。矩形工具的两条反光也能给出初值，角点与斜边可以支持局部圆拟合。增加相邻斜向梯度门仍在 75 个人工硬负例中新增 35 个误检，基线为零。已撤下这一实现。严格模板峰直接作为唯一圆初值时，现场子序列零增益。保留版本同时要求运动历史、双外观和当前独立轮廓。[宽松实验负例](synthetic_tools.csv) · [负例图](synthetic_tools.jpg)

最终集成负例在完整 moving_fast_confirmed 三个新增时刻，复制该时刻已有真实检测历史，把当前真球位置替换成 5 种转角 × 5 种宽度 × 3 种高度的双高光工具。225 次中，补搜新增 0 次。普通 Hough 本身接受了其中 5 次，因此两版的总工具候选均非零。真实 tool_only 的 120 帧纸尺均有效，两版均为零候选。[已授权状态的工具挑战](integrated_armed_tools.csv) · [工具实片](integrated_tool_only.csv)

`integrated_*`、`fresh_*` 为 BallDetector 正常入口双版本结果。前者来自 7/motion_20261121 及旧工具片，后者来自 8/continuity_20261122；新 −5 使用 left_points_edgeknot，新动态片使用 dynamic_points_digits。其余有前缀的数据用于消融：`motion_*` 为直接模板初值，`guarded_*` 为单次补搜，`extension_*` 为延长一次的实验；无前缀的场景回放为被否决的全域双高光实验。回放后仅给已通过的候选增加来源标记，冻结跟踪器不读取该字段。当前协作跟踪器的附加行为由 tracker 子目录独立验证。
