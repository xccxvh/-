# 纸尺 12 cm 连续回中实测

本轮实现 50 Hz 连续 PWM，并在当前球位运行了闭环。补光后的 183445 实验从首次偏转到最后一个控制写入持续 3.405 s，中间没有回中位，球仍在纸尺 9.68～9.73 cm。所有批次在 11.70～12.30 cm 带内的实测保持时间均为 **0 s**。每轮都取得了 STOP 后停用及 1324 ticks 中位回执。

## 控制与辨识

- 方案 C 及原 points 厘米模型生成视觉测量。控制线程在接纳新曝光时检查 100 ms 门限，用实际曝光间隔做 α–β 更新。估计曝光位置、控制时刻预测位置、最后有效曝光和接收时间分别记录。心跳间隔 20 ms，跳过错过的发送周期。
- 近期无新帧时保持驱动，可依据预测提前撤力。多帧缺测时只允许向上一次可信曝光附近已回读的同向 PWM 退让。自最后有效接收超过 220 ms、位置接近端部或遥测异常会停止。现场范围 1236～1413，GET_PARAMS 回报中位 1324、边界 1147～1502、速率 180 舵机度/s。
- 速度规划结合距离、制动减速度和延迟，速度反馈决定期望加速度。只在有观测时更新正反向起滚记忆与稳态偏置。独立辨识入口可持续施加一个有界偏移，观察同向位移后转入反向制动。
- 先验设定为正、反方向每 tick 对应 0.55 cm/s²、可用制动减速度 6 cm/s²、延迟 0.12 s，速度反馈系数 3.2/s。当前沿用历史观测到的负极性。经确认上电的批次尚无持续起滚和独立反向制动区段，**实际两向增益、制动能力、机械延迟、起滚门槛和目标平衡 PWM 都未辨识**。1324 是软件中位。
- 约 10 cm 到 12 cm 尚未完成。按现场指示保留当前球位，本轮未做 14 cm 起点。下次应在同一录像中核对回读到 1282 或 1264 ticks 时连杆及轨道的实际响应，并使此姿态下的纸尺身份可持续验证，再取实物运动段拟合参数。这一步能区分局部阻力、机械传递和视觉中断。

## 复现

在当前 Nano 工程目录运行。窗口数字对应本次现场已确认的装配。带电实验包括停车、舵机有电及钢珠自由三个条件。

```sh
export OPENBLAS_CORETYPE=ARMV8 OPENBLAS_NUM_THREADS=1
python3 nano_experiment.py --serial /dev/ttyACM0 adaptive \
    --min-ticks 1236 --max-ticks 1413 --seconds 25 --record
```

通过同一入口增加 `--identify-offset -52` 可选择恒定偏移辨识。已获得独立拟合结果时，`--model FILE` 可输入 gain_pos、gain_neg、brake_accel、delay_s。各批次曝光与补光变化如表，正式视觉配置沿用原文件。此次原生日志记录环境为 Nano Python 3.6、OpenCV 4.1.1。最终 Nano 上控制、估计与协议专项 20 项通过；电脑端完整测试 350 项通过。

从仓库根目录运行下列分析可复算批次指标。预测位置不参与精度或持稳验收。

```sh
python3 -B Jetson/docs/velocity_return_20261126/analyze.py --neutral 1324 \
    --summary-only Jetson/docs/velocity_return_20261126/field/logs/experiment*.csv
```
