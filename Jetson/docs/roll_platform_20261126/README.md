# 纸尺 11 cm 朝 12 cm 的带球实测

停机后 54 帧中有 48 帧厘米位置有效，纸尺位置中位 10.888 cm，范围 10.872～10.897 cm。目标为 12 cm。本轮未观测到持续向目标起滚或进入 11.7～12.3 cm。最后的 G3519 STOP 已确认，输出回到 1324 ticks。

静止时原曝光与新曝光的球心检出分别为 85/101 和 103/107。曝光调整未改变参考图或厘米模型。两段 10 ms 无录像试验均保留每帧 CSV；另有同球位的 1310 ticks 录像。没有可用于估算反向制动能力、双向起滚量或保持时间的实物轨迹。空载时深负侧反复出现错峰，带球试验末段也存在已确认轨道但输出超龄的情况。下一次带球测试前宜同步测量带载两端高差，并在相同姿态确认新鲜观测能持续覆盖平台。当前数据不足以区分局部凹陷、摩擦或实际杆角不足。

## 工具与记录

空载使用 nano_experiment.py 的 scan --platforms 与 --record，保存每个平台的遥测、标注视频和按曝光时间命名的全幅原图。带球使用 adaptive --identify-platforms 和 --brake-ticks，回读到位后观察真实位移，识别到同向起滚时转向制动；原有 50 Hz 输出、现场行程、端部和缺测停机继续生效。固定平台辨识不调用速度规划器。以工作范围 1236～1413 为界，板端实时参数为中位 1324、固件范围 1147～1502、软件速率 1600 ticks/s。

两轮空载诊断与冻结右侧新框试验见[逐平台报告](unloaded_identity_zh.md)。对新框重新拟合并按真实已知位置回放，旧批次独立 +5 cm 有效 140/150，低于 95% 要求，因此现场继续使用既有参考和标定。逐点结果见[新框独立验证](right_patch_placements.csv)。
