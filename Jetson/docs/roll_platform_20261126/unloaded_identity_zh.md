# 空载平台扫描的尺面身份与位移

## 给带载试验的结论

- **两轮都不能支持双向自由球闭环。** 从 1324 向下，1264 / 1246 / 1236 三档在两轮合计的后段仅 1/71、11/58、3/67 帧确认尺面。1282 后段也只有 12/16、12/30。一次失败后再等一秒不能解决问题。
- **正侧可作为受约束带载观测的候选。** 1384、1402 的两轮后段分别合计 43/43、43/43。初测两档全程通过，复测也全程通过。1366 在复测后段为 26/27。可先在操作人员可控、球有物理限位的条件下验证严格尺面身份、已绑定标定和实测球心；这份记录没有检验带载运动、球速或闭环制动距离。
- **回中也要看当前帧。** 从 1236 回到 1324，后段两轮均全过。从 1413 回同一 1324，后段只有 8/14、20/26。右侧回中后，两侧印纹相对初始分别仍有约 (−4,+6)、(−6,+3～4) px 偏移，下一轮开始时仍可见。可能有回差、装夹或机构姿态差异，单相机和 PWM 回报不能区分。失去身份时应继续使厘米反馈无效。
- **首要光学问题是右侧重复印纹。** 负侧深段 36 张原图里，有 35 张在右侧主模板的全窗检索中选到偏离实际印纹超过 40 px 的峰；正侧 1366～1402 的 36 张为 0。现场图像贴近原纵向搜索边缘；131 张样本把纵窗从 ±96 扩到 ±120，身份结果逐张相同。

## 逐平台实测

分子是 `rail_identity_valid=1` 的已处理帧数，百分比按帧计算。两次扫幅一致，平台分别约 2 秒和 3 秒。起点是接收端首次读到已使能、成功、实报输出与目标一致的 0x82；通过 command_seq 追溯 TX 平台号。用同一主机单调时钟的曝光起点 SOE（`uart_frame_time_ms`），逐帧核对已验证标志和 link 日志发送的 capture_ms32。三次 1324 分段统计。首次到值前、最终停机回报后的帧不归入平台。

常规区间截至下一段首个到值 RX（末段截至禁用 RX）。命令发送到新 RX 之间机构可能已经开始动；另列保守后段，截至下次新平台首 TX 或 STOP 请求。两轮这个边界差分别为 69～81、94～100 ms。SOE 到应用取帧时间的中位差两轮都约 48 ms，不能拿应用取帧、TX 时刻或视频帧率代替曝光。后段指时间窗，未测得机械绝对角度。

## 光学与失败细节

**搜索范围。** 主模板中心相对标定照片的估计位移，全部 JPG 的 dx 范围 −42.3～−12.4 px，dy 为 −95.0～−72.0 px。以现场纹理为引导，在同名印纹附近 ±5 px 用三组原照片模板复查，最低整数峰首轮 −96、复测 −95 px。结合定位误差可判断部分样本贴边，当前采样没有明确越过 ±96 的证据。纵向扩大至 ±120 的离线严格回放首轮仍 41/53，复测仍 55/78，且逐帧无翻转。此处检查的是尺面身份窗；两轮空载没有已确认球心，不能判球心是否越过物理搜索区。

**两端位移不同，但无法从本次记录唯一归因于透视。** 首轮 1236 后段左块 (−13,−9)、右块 (−9,−4)；1413 后段左块 (+12,+14)、右块 (+5,+6)。复测重现，方向相关的旋转、尺度或局部视角变化都可能影响与旧照片的匹配。以同一实拍纹理块的拉普拉斯方差比衡量锐度，深负三档的中位比为 0.87 / 0.81，高于正侧三档的 0.67 / 0.73（首轮 / 复测）。指标也受噪声、对比度和 JPEG 影响，不能反推曝光期间运动量。持续错峰、后段失效和正负方向对照共同说明瞬态运动模糊不足以解释主要损失。

**同一错峰在复测重现。** 13489.448575.jpg 的原主模板右块全域最高峰位移为 (+29,−95)，同名印纹实在 (−29,−90)，横向相差 58 px。错峰 NCC 0.819，正确峰 0.788，峰差 0.032。三点相似拟合最大残差 21.33 px；只作诊断地选回同名印纹后为 2.36 px。复测 13601.547339.jpg 的对应结果为 (+28,−94) 与 (−29,−90)，错峰 / 同名分数 0.837 / 0.805，最大残差 20.99 / 2.36 px。即使几何可解释，正确纹理本身仍可能低于原强度门限 0.85。不能把小窗里的次峰当成身份依据。末次回中还有另一种失效：13502.164592.jpg 主模板三个峰都接近同名印纹，最大残差 2.509 px 略过 2.5 px，同时右块峰差仅 0.013，低于要求的 0.05。

## 单项离线试验：替换原照片的右侧主框

**冻结的候选仅供离线复验。** 在 `config_static_fast_c.json` 的内存副本中，将 `rail.upper_reference.boxes[2]` 从 `[901,635,71,31]` 改成 **`[915,650,40,17]`**（原照片左上 x、y、宽、高，像素）。左、中主框、备用三框、数字三框、±96 全窗、竞争门限和上缘约束全部沿用原值。新框包含原右侧数字子框，以数字及邻近边界减少重复刻度的影响。照片为 `assets/topview_20261120/moving_reference.png`，SHA-256 为 `3c6da668646e530e87fc80368bd68fdef1be0c5f59344afd466ba7cc1505eff3`。

只在第一轮 53 张上比较同一项改动的 13 个较宽裁框和 64 个较窄裁框。按已通过姿态是否偏离实拍纹理、严格身份净变化、深负侧错峰及有效数择优，随后冻结上述唯一候选。第二轮 78 张只用于该候选的验证。两轮均按各自 SOE 顺序回放，保留同帧重定位及原有拒绝规则。第二轮与第一轮同场景，是重复扫描的留出集；尚无独立机位、光照、带球和厘米真值验证。

**假位移检验。** 在起始中位、1264、1236、1384 和末次回中实拍图上各做三种独立冷启动对照：把右块整片实拍纹理复制到右方 86 px 并保留真块；只保留错移副本并遮去真块；只遮去真块。竞争中心都在原搜索域内。每种首轮 24、留出 35 张，两种配置均拒绝全部 177 个干预输入。该检验覆盖单块错移和遮挡；未检验整把相似纸尺替换等场景。

**采用判断与标定。** 候选在留出集减少了右块错峰，但仍有旧有效帧损失和深负侧长时间不可用的风险。本次建议保留现行现场配置。若后续继续评估，先按新框和原始参考图、相机/焦距、分辨率、畸变模型与算法版本生成独立绑定；以独立有真值的多位置样本拟合新厘米模型，并在未参与拟合的数据上分别检验中位、两侧、双向回中以及带球状态的误差与身份覆盖，沿用项目既有验收标准。原配置及其厘米模型只能用于原绑定。本次仅在内存中构造视觉匹配器，没有生成、重写或切换任何运行时绑定。

复算已冻结候选用 `python3 -B diagnose_right_patch.py 915 650 40 17`。开发筛选用 `python3 -B diagnose_right_patch.py --develop`，该入口只读取第一轮图像。
