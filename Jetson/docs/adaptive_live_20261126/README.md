# 纸尺 12 cm 实板回中试验

目标为控制坐标 0 cm，到达带为纸尺 11.70～12.30 cm。使用方案 C、原 points 厘米模型和 REMOTE。每轮以 0x82 回读确认停止及中位。文件名采用 Nano 自身的日历时钟。各轮运动、速度和缺测间隔以 CSV 内的单调时间计算。

板端 GET_PARAMS 回报中位 1324、软件行程 1147～1502 ticks、限速 180 舵机度/秒。先在 1280～1368 ticks 内试探，随后采用现场确认的 1236～1413 ticks。PWM 回读代表软件输出，实际杆角未经独立测量。

| 板上记录尾号 | 现场条件 | 纸尺位置及结果 |
|---|---|---|
| 174123 | 正向 PWM 辨向 | 从 10.59 cm 到 10.26 cm，末段速度 −1.42 cm/s，确认增大 PWM 对应本次向小刻度滚动 |
| 174234 | 反向 PWM 回中 | 从 9.92 cm 到 10.10 cm，末段参考失配和超龄造成缺测 |
| 174551 | 补光，20 ms 曝光 | 从 10.09 cm 到 9.97 cm，最后连续 4 帧超出 100 ms |
| lit10/174903 | 补光，10 ms 曝光 | 静止预检去掉最初 6 帧后 110/110 帧有效。闭环输出到 1266 ticks，位置 9.94～10.07 cm |
| lit10/175116 | 短曝光，区分位置与测速超时 | 位置 9.95～9.99 cm。有效位置间夹杂模板竞争与超龄，速度恢复超时后停止 |

闭环判断只使用曝光年龄不超过 100 ms 的当前实测位置。向外驱动分多个心跳写入，单步不超过 15 舵机度。短时纯超龄时等待新帧；缺少可信速度时回中位等待。原始配置使用 20 ms 曝光；lit10 仅将相机 time_100us 改为 100，其余参数相同。每轮起止位置取自 REMOTE 使能期间的有效视觉记录。两轮之间无人记录的位置变化不能用于运动辨识。

上述各轮均未进入目标带。静止时定位可靠，驱动时的帧龄和纸尺姿态证据不连续，尚不能确认从约 10 cm 自动回中。
