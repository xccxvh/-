最终轮 324 个视觉处理帧中有 320 个厘米有效。控制窗口内记录 287 个新鲜测量，跨度 11.71 秒。球心纸尺读数从 10.728 到 10.718 cm，全程在 10.690～10.773 cm。板端已执行 1324 到 1368 ticks 的递增指令，每级最多增加 3 ticks（约 0.34° 绝对舵机角）。最高平台有 17 次新鲜测量，跨度 0.604 秒，位置范围 10.711～10.720 cm。131 帧 0x81 遥测中内部 AUTO 始终关闭，退出后的 0x82 确认输出恢复 1324 ticks。

初始中位与上限平台的球心图像横坐标中位数分别为 553.63 与 560.11 px；轨道图像方向中位数分别为 1.378° 与 1.153°。轨道相对厘米坐标仍接近原刻度。此项不能测出真实机械杆角。当前试探无法确定起滚方向、最小有效 PWM、两侧收敛、制动性能或稳态误差。下一项机械排查是独立观察 1324 和 1368 ticks 时两端的实际高差及舵机连杆位移，再检查当地轨面与挡具。

每轮均保留 experiment（控制阶段、PWM 和板端回显）、track（逐帧测量和绑定）、link（原始位置发送与板端控制遥测）及运行日志。run1/2/3 依次对应上述三轮。试验期间没有录像。

## 运行

现场确认的端点应落在固件窗口内。下例变量为确认后的整数 tick，程序运行时核对板端实际中位。视觉有效且起始球静止后进行短暂同向试探；根据真实位移辨向，在速度较快时卸力/制动，在目标附近回中位。方向和保持策略尚待在可起滚的机构上验证。

```sh
cd Jetson
OPENBLAS_CORETYPE=ARMV8 OPENBLAS_NUM_THREADS=1 python3 -B nano_experiment.py \
  --serial "$PORT" adaptive --min-ticks "$LOW" --max-ticks "$HIGH" --seconds 22
```
