# 轨道内新尺 12 cm 回中实测

以新尺 12 cm 为零，使用 e563c98 新参考和 points 厘米标定。7、12、17 cm 用于拟合。10、14 cm 独立摆放各有 116/120 帧有效，最大绝对误差分别为 0.025、0.099 cm。试验期间小车静止、钢珠自由；GET_PARAMS 返回现场行程 1236～1413 ticks，中位 1324 ticks。Nano 通过 REMOTE 输出，不使用板内 AUTO。

|阶段|新尺实测结果|结束状态|
|---|---|---|
|155532，20 ms 曝光、增益 25|从 13.909 cm 向左起滚；进入制动时估计 12.89 cm，随后越过目标，最低 11.074 cm，最后有效位置 11.097 cm|300 ms 缺测，STOP，输出 1324|
|155634，10 ms 曝光、增益 55|启动前监测中位 12.226 cm。运行中连续 486 个可信曝光，位置 12.113～12.265 cm，中位 12.227 cm；连续观测跨度 32.888 s，最大相邻间隔 104 ms，控制器连续 hold 计时最高 29.364 s|300 ms 缺测，STOP，输出 1324|
|停机后 3 s 复测|38/42 帧有效，12.213～12.257 cm，中位 12.223 cm|串口监测|

连续目标带时间取 experiment CSV 的真实曝光 capture_s，只计 valid=1、|x_cm|≤0.3 cm，相邻曝光间隔≤150 ms。hold 计时另外要求满足控制器的低速条件。第一轮越过目标后曾超调约 0.93 cm；两轮之间没有连续控制记录，第二轮开始时已经回到目标带。本次证实了从右侧驱动和目标带内保持；完整的一次不中断的 14→12 cm 稳定回中仍待验证。
