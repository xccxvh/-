# Nano 直接 PWM 回中 · 离板版

目标是纸尺 12 cm，对应控制坐标 0 cm。本次在电脑上修改并验证 Nano 程序。实际硬件的最后一段记录仍是 11 月 26 日停机后纸尺 10.888 cm。本轮没有新的运动录像、起滚 PWM、回中时间或实测保持时间。[历史实板记录及录像](../roll_platform_20261126/README.md)

## 运行入口

从 Jetson 目录执行以下命令可在后续有人监护的板测中选择正式控制器。命令中的行程来自当前装配的现场确认。更换连杆、舵机安装位置或轨道后，应重新确认行程，并用独立的经验文件。

```bash
python3 nano_experiment.py --serial /dev/ttyACM0 adaptive \
  --min-ticks 1236 --max-ticks 1413 --record
```

程序查询 G3519 的 GET_PARAMS，用现场行程与板端实报范围交叉核对，经 REMOTE 下发 0x02。板端 a2edda1 的 0x82 分别报告接收序号和 10 ms 执行节拍的目标，Nano 允许单次跨档回报上一目标，学习仍要求核对实际到位时间。0x01 继续提供带曝光时间的诊断坐标，控制有效位为 0；G3519 的内部 AUTO 不参与。可用 Ctrl-C 或板上本地停止。可以显式设置 --seconds 限定一次试验时长。默认在达标后继续保持，连续真测满足目标带和低速条件满 10 秒时写入 hold_confirmed。STOP 有板端退出和中位回读确认。

## 相对基线 34d7e605 的变化

| 旧设置 | 正式回中路径 |
|---|---|
| 最大目标速度 4 cm/s、期望加速度 ±12 cm/s²、映射 0.55 | 直接选择 PWM。起滚、移动、制动及保持均不经过该速度规划器。显式提供 --model 才会使用历史速度规划分支 |
| 固定 8 ticks/s 起滚，以及 Nano 对向外加力的额外限速 | 无统一软件输出斜率。首次试探采用 10 ticks，实测仍静止时初始每档加 8 ticks。平台观察依据连续真位移和已执行 PWM。舵机运动限速在 G3519 执行 |
| 固定 2.5 s、移动 0.28 cm 即制动、制动满 0.7 s 即结束 | 这些行为仅存在于显式恒定平台辨识。正式路径起滚后延续已产生实测运动的 PWM，在慢移、明显加速、重新受阻时调整。反向制动由剩余距离、方向和实测速度共同决定，结束依赖运动状态 |
| 速度固定裁到 ±15 cm/s | α–β 按实际曝光间隔更新。显著偏离预测的点需要下一真实曝光支持同一轨迹，连续可信的高速测量可以超过 ±15 cm/s |
| 每次清空起滚经验、保持在软件中位 | 按纸尺 7～17 cm 每两厘米分区，分别记录两方向上与真实位移对应的回读 PWM、制动轨迹与中心平衡证据。STOP 确认后将新增经验原子保存到 roll_experience.json，可通过 --experience 指定路径。空白经验不预填阈值；保持在 PWM 域使用位置、速度反馈和慢偏置 |
| 100 ms 编码门限叠加 220 ms 接收时间超时 | REMOTE 使用同一单调时钟上的曝光年龄。150 ms 内的新真测可调整控制，之后保持最后指令；最后可信曝光超过 300 ms 则停止。无效帧打断稳态验收，短时缺测保留速度和驱动力。直接使用板内 AUTO 的旧串口入口仍有其自身 100 ms 规则 |

控制器沿用已确认的机械行程、实际/预测端部保护、串口回执与输出跟随检查、板端故障或本地停止、持续视觉缺测退出。达到现场行程端点时，还需确认实时与曝光对应的 PWM 均到位，且连续实测球心未产生可辨运动，才触发无运动退出。所有输出限幅均允许覆盖现场已确认的完整区间。启动动作、移动判断、初始制动距离和 PWM 域保持增益仍是调试参数，制动优先查找同方向、速度接近的实际停车轨迹。

## 实物验收状态

现场行程内两侧有效起滚、10 cm 和 14 cm 两侧回中、反向制动、12±0.3 cm 连续实测保持满 10 秒均待实板验证。后续应在同一次带球试验中核对视频时间戳、真实球位、曝光对应 PWM 和实际回读。没有运动证据的区段继续留空。
