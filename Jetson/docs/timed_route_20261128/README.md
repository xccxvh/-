# 新尺 12→17→7 cm 五秒折返

2026-11-28，使用新尺 points 模型，起点为纸尺 12 cm。控制器先请求 +5 cm，在接纳的曝光实测位置进入 +4.3～+5.7 cm 时切至 −5 cm。验收还需核对实际回头位置，预测坐标不能证明到达。五秒从 START_REMOTE 命令发出前起计。末端稳定采用实测误差不超过 1 cm、估速绝对值不超过 0.35 cm/s；若五秒内已经进入稳定段，额外观测以确认至少 1 s，记录进入时刻及确认时刻。1 s 和速度阈值为本次工程判据。旧尺或超出已验证映射域的数据不能证明达标。

实板 160502：起始 11.953 cm，75 个控制器接纳的曝光测量范围 11.945～11.986 cm，最后有效读数 11.980 cm。板端输出从 1324 降至现场允许下限 1236 ticks，并有 30 帧连续到位回报，首尾间隔 2.899 s。录像显示纸尺随轨道移动，钢珠相对于 12 cm 刻线几乎未移动。五秒截止时没有到达正端，没有折返；末端稳定时间和端点最大误差均无可用验收样本。已确认 STOP 和 PWM 1324 ticks，遥测 CRC 错误为零。PWM 是软件回读，局部坡度、摩擦和舵机实际角度均未独立测量。

实测后给路线模式补上与原 O 点控制器相同的端点无运动提前退出；这项提前退出只做了软件验证。保持原有视觉时效、通信和机械范围。设备实测用 10 ms 曝光、增益 55。Nano 文件名取板端日历，曝光与控制用单调时钟。

板端实验入口（目录内 config_static_fast_c.json 已装入新尺配置和绑定资源）：

```bash
OPENBLAS_CORETYPE=ARMV8 OPENBLAS_NUM_THREADS=1 python3 -Bu nano_experiment.py --serial /dev/ttyACM0 adaptive --timed-route --min-ticks 1236 --max-ticks 1413 --record
```
