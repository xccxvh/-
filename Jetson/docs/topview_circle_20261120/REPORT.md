# 俯视机位原图钢珠识别实测

Nano 独立部署目录为 `~/topview_circle_20261120/vision`。新配置为 `config_topview_circle_20261120.json`，同一机位原浅球冠配置为 `config_geometry_topview_raw_20261120.json`。两者均使用原始 1280×720 图像、原纸尺纹理和动态 ROI。

## 失败原因及修改

四段原片能看到直径约 50～60 px 的球体。旧检测器只分割上缘上方 3～28 px 的区域，并在上缘上方 29～45 px 取背景样本；俯视时采样带本身可以落在球上。Lab 掩膜截断球体，将其分成细条、孤立亮斑。第 60 帧，O 和 −5 cm 真球处的最大分量宽度分别只有 5 和 6 px，+3 cm 为 10×12 px；+5 cm 为 12×25 px，被宽高比拒绝。部分分量还因弧形条件被拒。O 点的固定工具与纸尺相邻，局部反光恰好形成原模型可接受的宽浅凸起，位置连续性又足以建立跟踪。图中红线为旧有效输出，白色为旧检测器实际使用的二值掩膜，绿色十字为新输出。[同帧原图、掩膜及结果](raw_mask_result.jpg)

新检测器只在纸尺动态 ROI 的窄带内用 Hough 生成圆候选。它沿圆周检查内外亮度梯度，要求左右两侧都有支持；拟合时排除被轨道唇边遮住的下缘，检查残差、纸尺两侧边缘支持及球体内部的高光对比。中心须落在动态搜索范围内。输出当前帧拟合圆心，测量版本为 `topview-circle-v1`。跟踪保持原有五帧建立、外观连续性、歧义和失效保护。新旧测量版本分别绑定，旧厘米模型不能直接复用。

## Nano 同帧回放

原片 SHA 见 scores.json。沿用上一轮已经固定的逐帧球心标签及人工可见球体半径，按原有半径加 1 px 的二维身份标准复核全部输出。另算横向中心误差和抖动。全部 480 帧均纳入，包括启动及参考失效。抖动为正确测量的横坐标标准差，最长连续漏检列依次为全段和首次确认之后。

| 位置 | 旧版正确 / 误检 | 新版正确 / 总帧 | 新版误检 | 最长连续漏检，全段 / 确认后 | 抖动 px | 对标签的平均 / 最大横向绝对偏差 px |
|---|---:|---:|---:|---:|---:|---:|
| O | 0 / 43 | 112 / 120 | 0 | 8 / 0 | 0.86 | 1.76 / 2.83 |
| −5 cm | 0 / 0 | 107 / 120 | 0 | 4 / 2 | 1.94 | 3.84 / 9.15 |
| +3 cm | 0 / 0 | 116 / 120 | 0 | 4 / 0 | 0.44 | 0.90 / 1.61 |
| +5 cm | 0 / 0 | 115 / 120 | 0 | 4 / 1 | 1.12 | 1.35 / 5.28 |

总计 450/480 正确，零误检。O 点开头有轨道参考失效，首次确认后连续正确 112 帧。+3 cm 有一帧跟踪器关联到了真球，但存在多个候选；轨道坐标模块按原约束没有输出该帧的轨道坐标，全段可用于轨道坐标的帧数为 449。所有厘米和反馈有效位为零。这四段静态片参与了开发，动态滚球、机位变化和其他光照条件仍待独立验证。[逐帧结果](frames.csv) · [典型漏检帧](misses.jpg)

另行移走钢珠，保留黑色固定工具，在同一原始预览录制 120 帧，Nano 正式入口回放。轨道参考有效 120/120，候选 0 帧，有效输出 0 帧。[无球原片截帧](tool_only.jpg) · [负样本记录](tool_only.json)

## USB 直采性能与标定判断

Nano 的 benchmark_live.py 模式 A，1280×720 MJPG，先旧后新，同场各 10 秒，钢珠静止且手移出画面。处理 FPS 含全部已处理帧。新算法共有 287/292 帧有效像素输出，实时测试没有逐帧人工标签。

| 指标 | 原图浅球冠 | 原图俯视圆心 |
|---|---:|---:|
| 采集 FPS | 29.18 | 29.23 |
| 处理 FPS | 20.32 | 29.13 |
| 算法均值 / P95，ms | 47.43 / 49.93 | 32.62 / 33.79 |
| 轨道参考有效帧 | 204/204 | 292/292 |

电脑与 Nano 分别通过 242 项软件测试。可以开始当前机位的独立静态厘米标定，拟合和验证应使用不同刻度；−5 cm 端存在最大 9.15 px 的横向偏差，需要重点复核。在新标定和独立动态验证完成前，厘米精度及运动时连续性待测。

可在 Nano 的独立目录使用 `python3 main.py --config config_topview_circle_20261120.json --video /path/to/raw.mkv --fps 30 --csv --label O` 回放。四个位置的标签依次使用 O、minus5、plus3、plus5。电脑在 Jetson 目录运行 `PYTHONPATH=. python3 docs/topview_circle_20261120/evaluate_static.py --clips /path/to/geometry_comparison --logs /path/to/new_nano_logs --output /path/to/results` 可重建同帧统计和可视化。
