## 修改及复核

- 快搜从上次成功的模板组开始，使用本帧三块实测纹理，复核竞争峰和上缘。局部失败后同帧重定位，只缓存固定采样几何；旧配置仍可回放。三张相同板端原帧上，原检测参考耗时中位 28.67～30.86 ms，快搜 17.57～17.65 ms。
- 两块 V4L2 缓冲实测采集 29.84 FPS，SOE 到解码完成中位 47.65 ms。单块只获得 14.91 FPS，中位 47.12 ms。旧入口处理后总等下一张新解码图；现在按 SOE 与近期处理预算判断单槽当前帧是否来得及。只改取帧的 8 秒对照依旧只有 14.84 FPS。全程保留同一种 BGR 解码和灰度换算。
- 仅控制模式、数据合格且唯一问题为超过 100 ms 时，编码器跳过该帧，不消耗线上序号。参考失效、钢珠丢失、预测位置、域外或标定失效、时钟异常等仍发送无效。停机明确发送无效；板端保持既有 150 ms 超时。真实位置和纯超龄均进入逐帧记录。
- 在 17 段已知位置录像上用独立绑定重新拟合、复验。9 段独立验收片共 1312/1350 有效，平均绝对误差 0.05292 cm，最大 0.28245 cm。正式文件入口回放相同验收片 1311/1350，最大 0.21459 cm；开发片 `new_verify_m5` 在该入口仍为 132/150、最大 0.45409 cm。此前补光困难片 59/60 帧确认参考，55/60 帧输出厘米。竞争纹理和遮挡的 30 个负例全部拒绝。
