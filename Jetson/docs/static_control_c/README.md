# 方案 C 轨道厘米验证

在当前固定机位、焦距和 POINTS 坐标下，历史静态已知刻度通过原厘米验收。运动补测在留出录像中有独立图像中心可供比较；动态实物位置的绝对误差仍缺同步真值。

## 配置、绑定和重放

`config_static_control_c.json` 继承 `config_motion_cm_20261122.json` 的 ball、tracking、ball_search、参考图、轴和内参。新增顶级 `static_control_motion=true`，厘米文件指向独立的 `rail_cm_static_control_c.json`。父类计算的八源基础绑定 ID 为 `5383532fc58169af534cd5a919bd77dd7738a02a362f30af93f7eec637500e11`。新增字段记录开关、基础 ID 和本机实际读取的三个实现文件 SHA-256。C 绑定 ID 为 `f1d0f2a2a100fd357d7463251a47406e8a7f8215d5d0b869ee7da31468897286`。配置 SHA-256 为 `87e7c20a600e7666b0675577845d089aa41673bc4f3a56c3c49300698323ff05`，模型 SHA-256 为 `cfd6195fd50523ef79b512dc310bd5e9506743c8595ae868078641e93be1e41d`。[绑定字段](evidence/binding.json)

每段原始 MJPEG 从首帧独立初始化检测器和跟踪器。每帧先调用正式 BallDetector，再调用生产 supplement 更新运动历史，有原候选即优先。补测候选经过当帧 topview_balls 或 _verify_topview_circles，跟踪器接收空搜索边界。当前帧单候选、身份、参考、点矫正和标定域检查均由正式实现执行。静态采样逐帧写盘，原 collect 读取各 CSV、绑定 sidecar 和原视频并计算真实 SHA-256，原 build_model 线性拟合并按独立位置验收，RailCalibration 加载时重算。除旧 −6 拟合片沿用 30 fps 名义时钟外，录像均使用原始帧时钟。该片没有帧时钟文件，逐摆放证据中的时钟摘要留空。

## 静态实物刻度

历史清单和实物确认取自 Git 提交 `08147c003476eb2b0eed792978d09b8ec8b6b820` 的 `docs/continuity_20261122/geometry/release/checks.csv`。两个历史 +3 摆放标称值与图像复核冲突，使用其分别重摆后的录像。零点复拍、开发片和旧第二次 −5 回归均单独评估。未用旧模型系数、厘米输出或历史逐帧测量参与拟合。

| 分组 | 独立片段 | 结果 |
|---|---:|---|
| 拟合 −6、0、+6 cm | 3 | 每段 146/150 个轴坐标，三个位置等权线性拟合 |
| 正式验证 −5、−3、+3、+5 cm | 9 | 1312/1350 个有效厘米值，覆盖 97.19%，加权 MAE 0.05200 cm，最大绝对误差 0.28245 cm |
| 其余已知摆放 | 5 | 每段 143–146/150 个有效厘米值，全部通过逐段门限 |

14 个非拟合摆放均按各自完整 150 帧检查 ≥95% 覆盖和最大绝对误差 ≤0.300 cm。最差误差来自新 +5 cm 片。独立盲测 −5 cm 有效 145/150，最大误差 0.12513 cm。全部 17 个静态片中直接由 motion 发布的点为 0。拟合域为 [−363.54153, 390.11149] 轴像素，±6 cm 拟合端点附近的单帧抖动可能超域，超域时正式模型无厘米输出。[逐摆放误差、时钟和原片摘要](evidence/placements.csv)

## 动态补测中心

在 `moving_final` 原片按现场处理日程和全帧日程各重放一次，只计直接由 motion 发布的球心。逐帧比对冻结 C 实验的候选来源、帧号及原图 x/y。采用既有独立图像中心标注，在同帧、同一套内参、尺配准和轴下分别投影标注点与补测点。仅在两点均落入标定域时计算厘米差。该差值衡量选中心造成的轴向偏差；参考配准和厘米模型的共同误差不会由这项比较显现。

| 重放日程 | 补测像素输出 | 有厘米输出 | 双方均在域内 | 最大二维中心差 | 平均 / 最大轴向差 |
|---|---:|---:|---:|---:|---:|
| 现场处理 | 13 | 8 | 7 | 10.39 px | 0.05981 / 0.19334 cm |
| 全帧 | 17 | 11 | 10 | 10.39 px | 0.05394 / 0.19334 cm |

两种日程来自同一原片，可比较帧去重共 10 帧。最大轴向差在第 558 帧。第 481 帧的补测点输出 −5.86407 cm，但标注点超出标定域，因此该帧没有可比较的模型厘米值。现有样本支持域内图像中心差 ≤0.3 cm；绝对动态厘米精度尚未验证。[现场逐点](evidence/moving_processed_projected.csv) · [全帧逐点](evidence/moving_all_frames_projected.csv) · [动态来源摘要](evidence/dynamic.json)

## 复现

在仓库根目录执行以下命令。两个输出路径必须尚不存在。模型内保存了证据绝对路径，移动输出目录重新生成时，证据路径及模型文件摘要会随之变化。来源检测模块、模型绑定、摆放选择、系数和精度均可逐项核对。

```bash
python3 -B Jetson/docs/static_control_c/replay.py /home/user/桌面/jetson_nano /tmp/static-control-c-evidence /tmp/static-control-c-model.json
```
