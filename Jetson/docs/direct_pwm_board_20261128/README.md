## 实际运动

最后一段录像确认了右侧起滚、越过目标、向左超调和向右返回。第一次向左起滚时板端回读 1413 ticks。第一次进入 brake 时预测位置为纸尺 12.76 cm、估速 −1.98 cm/s，目标从 1413 改到 1314 ticks，随后球继续运动至 8.44 cm。返回途中第二次进入 brake 时预测位置为 10.74 cm，估速 +3.52 cm/s。覆盖目标不等于保持，连续有效曝光落入 12±0.3 cm 的最长一段仅两帧，首尾相距约 68 ms。未达到 10 s。

停机后，原图仍可见钢珠在 12 cm 长刻线附近。先以 5 ms 曝光监测 3 s，0/46 帧厘米有效，其中 26 帧竞争峰、2 帧参考不一致，另 18 帧跟踪仍在确认。恢复正式配置 20 ms 曝光后，3 s 内 0/45 帧厘米有效。实际静止位置的精确厘米值无法核验。保持 300 ms 退出保护，并优先解决当前姿态的纸尺纹理重复匹配，再根据此段过冲轨迹验证制动。保存的起滚和制动条目均来自单段实拍，尚待独立重复验证。
